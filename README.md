## Main project

### CiukiOS

CiukiOS is my open source RetroOS project.

The goal is to build a native legacy BIOS x86 system able to progressively run DOS and pre-NT software without relying on CPU emulation in the final runtime.

Repository: [github.com/PeronSlayer/CiukiOS](https://github.com/PeronSlayer/CiukiOS)
